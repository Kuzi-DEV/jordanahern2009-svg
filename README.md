### Hi, I'm Jordan.

I build systems that have to test their own assumptions before I trust them — mostly because I've been burned enough times by ones that didn't.

**Currently building: [TokIO AI](https://github.com/jordanahern2009-svg/Tokio-ai)** — an open-source financial research agent that won't call a pattern a "signal" until it's survived a permutation test, a minimum-sample-size check, and correction for every other hypothesis tested in the same conversation. Most AI stock tools will confidently describe a pattern in a handful of data points. This one is built to say when it can't.

A few things I actually believe about building this stuff:

- Ship one thing that fully works before you build the next thing.
- If a hypothesis dies, the interesting part is *why*, not just that it did.
- Never let a model guess at a fact you could just look up.
